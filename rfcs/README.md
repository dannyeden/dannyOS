# Request for Comments

RFCs propose changes that cross domain boundaries, alter constitutional
principles, introduce new canonical capabilities or objects, or affect safety,
privacy, or external compatibility.

## Lifecycle

`Draft → In Review → Accepted | Rejected | Withdrawn → Superseded`

An accepted RFC is not a substitute for updating the Canon. The author MUST
update affected chapters, the master index, and the decision log in the same
change or in explicitly linked follow-up work.

## Numbering

Use four-digit sequential identifiers: `0001-short-title.md`. Copy
[`0000-template.md`](0000-template.md) and do not reuse identifiers.

## Review

Every RFC identifies affected domains and required reviewers. Clinical safety,
privacy, security, financial, or regulatory consequences require reviewers with
the corresponding authority.
